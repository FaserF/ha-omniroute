# OmniRoute & Hermes AI for Home Assistant

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-41BDF5.svg)](https://github.com/hacs/default)

Home Assistant Custom Integration for **OmniRoute** and **Hermes AI Cognitive Engine**.

## Features

- **AI Task Entity (`ai_task.*`)**: Structured outputs, background analysis, smart home reasoning.
- **Conversation Agent (`conversation.*`)**: Assist pipeline integration with tool/intent calling.
- **Text-to-Speech (`tts.*`)**: Neural voice synthesis via OmniRoute `/v1/audio/speech`.
- **Speech-to-Text (`stt.*`)**: Speech recognition via OmniRoute `/v1/audio/transcriptions`.
- **Sensors & Diagnostics**: Live cascades, quota health, active sessions, and gateway telemetry.

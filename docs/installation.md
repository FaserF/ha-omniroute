# Installation

## Method 1: HACS (Recommended)

1. Open **HACS** in your Home Assistant instance.
2. Select **Integrations** from the top menu.
3. Click the three dots in the top right corner and choose **Custom repositories**.
4. Enter `https://github.com/FaserF/ha-omniroute` as the repository URL and select `Integration` as the category.
5. Click **Add**, then search for **OmniRoute** and click **Download**.
6. Restart Home Assistant.

## Method 2: Manual Installation

1. Download the latest release `omniroute.zip` from the [Releases](https://github.com/FaserF/ha-omniroute/releases) page.
2. Extract the archive into your Home Assistant directory under `custom_components/omniroute/`.
3. Restart Home Assistant.

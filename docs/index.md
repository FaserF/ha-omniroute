# OmniRoute for Home Assistant

A production-ready Home Assistant integration for OmniRoute, the high-performance AI Gateway and Router. Power your smart home with low-latency LLM routing, intelligent cascades, local privacy, speech processing, and autonomous generative tasks.

## ✨ Features

- **Assist Conversation Agent**:
    - Full Home Assistant Assist voice assistant integration with tool and intent calling.
    - Cascading LLM fallbacks (chat-cascade, coding-cascade, fast-cascade).
    - Customizable system prompts, temperatures, and token limits.
- **Generative AI Task Engine**:
    - Native AI Task platform for automations, reasoning, and smart notifications.
    - Multimodal vision support for security cameras and image analysis.
- **Health & Performance Telemetry**:
    - Gateway response latency in milliseconds.
    - Real-time active cascade health and model availability counts.
    - Network connectivity and cluster status binary sensors.
- **Quick Controls & Buttons**:
    - Ping/health checks and cache invalidation buttons.
    - Direct link to the OmniRoute Web UI.
- **Enterprise Diagnostics & Security**:
    - Full diagnostic export with automatic API key and credential redaction.
    - Safe local and authenticated remote deployment profiles.
